ToolPouch for macOS

Privacy Policy

ToolPouch is a collection of utilities for macOS. Most processing happens on your Mac. ToolPouch contains no advertising, does not use its own tracking analytics, and does not require a ToolPouch account.

Effective date: October 12, 2026

Local processing

Text encoding, JSON formatting, checksums, unit conversion, scientific calculations, and function graphs run locally. Image processing, metadata inspection, media inspection, hashing, and archive operations apply only to files you select.

Generated passwords and passphrases are not stored in the app database. Clipboard Inspector reads the macOS pasteboard while you use the tool; it does not save clipboard contents to the app database or iCloud. Copy actions place results on the system pasteboard, which is managed by macOS.

The SSH tool reads a folder you select and may remember access using a macOS security-scoped bookmark. Keys remain in your files and are not synchronized with Quick Copy Notes. Copying a private key requires confirmation.

System statistics samples are stored locally for the retention period you choose, from one to 24 hours. Network snapshots and device metadata are also local; up to 100 recent network snapshots are retained per device.

Quick Copy Notes and iCloud

Quick Copy Notes stores folder and collection names, note titles, descriptions and contents, favorites, ordering, and modification dates. When synchronization is available, this information is stored in the app's private CloudKit database associated with your Apple Account. Apple provides and operates iCloud. If synchronization is unavailable, the app can use a local-only store.

Quick Copy Notes is not a password manager and should not be used for passwords, private keys, or access tokens. You can delete notes and folders in the app. When iCloud synchronization is working, those changes propagate between your devices according to iCloud availability.

Network requests

Only tools that need external information make network requests:

  • Network Info contacts ipify to obtain your public IP address. The service necessarily receives the IP address of the connection.
  • Domain Lookup downloads the RDAP bootstrap registry from IANA and sends the domain you enter to the relevant secure RDAP service.
  • Network Check performs the DNS or connection check you request against the host and port you enter.
  • Maps and place-related actions use Apple services.
  • Quick Copy Notes synchronization uses Apple CloudKit.

External services may process connection information under their own policies. ToolPouch does not send text being transformed, generated passwords, SSH keys, clipboard contents, or selected local files to these services as part of local tools.

Permissions

  • Location: used by macOS to authorize nearby Wi-Fi discovery. ToolPouch does not upload Wi-Fi scan results.
  • Screen recording: used by Color Picker to inspect a small area around the pointer while picking. Captured pixels are not saved or uploaded by ToolPouch.
  • Selected files and folders: used only for the file operation you initiate and, where requested, to remember access to your SSH folder.

You can change permissions in macOS System Settings. Denying a permission limits only the tool that needs it.

Storage and deletion

You can delete Quick Copy Notes in the app. Files created in locations you select remain there and are not removed when the app is uninstalled. Local app data is stored in the macOS app container; deleting the app may not delete that container. Synced data can also be managed through your iCloud settings.

Children, advertising, and tracking

ToolPouch is a general-purpose utility and is not directed to children. It contains no advertising SDK and does not track users across apps or websites.

Polityka prywatności

ToolPouch to zestaw narzędzi dla macOS. Większość operacji odbywa się na Twoim Macu. Aplikacja nie zawiera reklam, nie używa własnej analityki śledzącej i nie wymaga konta ToolPouch.

Data wejścia w życie: 12 października 2026 r.

Przetwarzanie lokalne

Kodowanie tekstu, formatowanie JSON, sumy kontrolne, konwersje jednostek, obliczenia naukowe i wykresy funkcji działają lokalnie. Obróbka obrazów, odczyt metadanych i multimediów, hashowanie oraz archiwizacja dotyczą wyłącznie plików wybranych przez użytkownika.

Wygenerowane hasła i frazy nie są zapisywane w bazie aplikacji. Inspektor schowka odczytuje schowek macOS podczas korzystania z narzędzia; nie zapisuje jego treści do bazy ani do iCloud. Kopiowanie umieszcza wynik w schowku systemowym zarządzanym przez macOS.

Narzędzie SSH odczytuje wybrany folder i może zapamiętać dostęp za pomocą mechanizmu security-scoped bookmark systemu macOS. Klucze pozostają w plikach użytkownika i nie są synchronizowane z Quick Copy Notes. Skopiowanie klucza prywatnego wymaga potwierdzenia.

Próbki statystyk systemowych są przechowywane lokalnie przez wybrany okres od jednej do 24 godzin. Migawki sieci i metadane urządzenia również pozostają lokalne; aplikacja przechowuje do 100 ostatnich migawek sieciowych na urządzenie.

Quick Copy Notes i iCloud

Quick Copy Notes zapisuje nazwy folderów i kolekcji, tytuły, opisy i treść notatek, ulubione, kolejność oraz daty modyfikacji. Gdy synchronizacja jest dostępna, informacje są przechowywane w prywatnej bazie CloudKit aplikacji powiązanej z kontem Apple użytkownika. iCloud jest dostarczany i obsługiwany przez Apple. Jeśli synchronizacja nie jest dostępna, aplikacja może korzystać wyłącznie z magazynu lokalnego.

Quick Copy Notes nie jest menedżerem haseł i nie powinno służyć do przechowywania haseł, kluczy prywatnych ani tokenów. Notatki i foldery można usuwać w aplikacji. Przy działającej synchronizacji zmiany są przenoszone między urządzeniami zgodnie z dostępnością iCloud.

Połączenia sieciowe

Żądania sieciowe wykonują tylko narzędzia potrzebujące danych zewnętrznych:

  • Network Info kontaktuje ipify w celu uzyskania publicznego adresu IP. Usługa otrzymuje adres IP połączenia.
  • Domain Lookup pobiera rejestr RDAP z IANA i wysyła wpisaną domenę do właściwej bezpiecznej usługi RDAP.
  • Network Check wykonuje wybrane sprawdzenie DNS lub połączenia z podanym hostem i portem.
  • Mapy i działania związane z miejscami korzystają z usług Apple.
  • Synchronizacja Quick Copy Notes korzysta z Apple CloudKit.

Usługi zewnętrzne mogą przetwarzać informacje o połączeniu zgodnie z własnymi zasadami. ToolPouch nie wysyła do nich tekstu poddawanego przekształceniom, wygenerowanych haseł, kluczy SSH, treści schowka ani wybranych lokalnych plików w ramach narzędzi działających lokalnie.

Uprawnienia

  • Lokalizacja: używana przez macOS do autoryzacji wykrywania pobliskich sieci Wi-Fi. ToolPouch nie przesyła wyników skanowania.
  • Nagrywanie ekranu: używane przez próbnik koloru do odczytu niewielkiego obszaru wokół wskaźnika. Przechwycone piksele nie są zapisywane ani przesyłane przez ToolPouch.
  • Wybrane pliki i foldery: używane tylko do operacji zleconej przez użytkownika oraz — na żądanie — do zapamiętania dostępu do folderu SSH.

Uprawnienia można zmienić w Ustawieniach systemowych macOS. Odmowa ogranicza tylko narzędzie, które potrzebuje danego dostępu.

Przechowywanie i usuwanie

Notatki Quick Copy Notes można usuwać w aplikacji. Pliki utworzone w wybranych miejscach pozostają tam i nie są usuwane wraz z aplikacją. Dane lokalne znajdują się w kontenerze aplikacji macOS; usunięcie aplikacji może nie usunąć kontenera. Dane synchronizowane można także kontrolować w ustawieniach iCloud.

Dzieci, reklamy i śledzenie

ToolPouch jest narzędziem ogólnego przeznaczenia i nie jest kierowane do dzieci. Nie zawiera reklam ani mechanizmów śledzących użytkowników między aplikacjami lub witrynami.
